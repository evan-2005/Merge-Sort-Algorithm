# Merge Sort Implementation in Python

This repository contains a clean and efficient implementation of the **Merge Sort** algorithm using Python.  
Merge Sort is a **divide-and-conquer** sorting algorithm known for its predictable performance and stability.

---

## 📌 Features

- Recursive divide-and-conquer approach
- Stable sorting algorithm
- Handles edge cases (empty input, single-element list)
- Easy-to-read and well-documented code

---

## 🧠 How Merge Sort Works

1. Divide the array into two halves
2. Recursively sort each half
3. Merge the sorted halves back together
4. Repeat until the full array is sorted
